# Melaporkan masalah keamanan

Ini adalah proyek website kelas sekolah yang berjalan sebagai berkas statis. Tidak ada backend atau sistem autentikasi.

Jika menemukan masalah, sampaikan secara pribadi kepada maintainer atau Owner proyek. Jangan membuat issue publik yang berisi kode Dashboard, data siswa, nomor telepon, token, atau informasi pribadi. Sertakan langkah reproduksi yang aman dan dampak yang terlihat; jangan mengakses atau mengubah data orang lain.

Gerbang Dashboard hanya kenyamanan, bukan keamanan. Jangan simpan informasi rahasia di aplikasi ini.
